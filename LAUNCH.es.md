# Borrador para LinkedIn — preview, no lanzamiento estable

Estamos construyendo Agent Office: una oficina visual para coordinar agentes de desarrollo alrededor de un playbook.

Partimos del proyecto open source Open Office, al que damos crédito, y abrimos nuestro fork para explorar una capa de misiones: qué etapa sigue, quién la lleva y qué evidencia hace falta para avanzar.

La primera versión incluye un explorador interactivo con datos simulados y un núcleo de playbooks con pruebas automatizadas. Todavía no incluye las conexiones de Jira y Confluence ni una demo completa con agentes reales. Esos son los próximos hitos.

Buscamos personas que ya trabajen con Codex o Cursor y quieran ayudarnos a validar este flujo.

Código: https://github.com/lucabecci/agent-office
Proyecto original: https://github.com/longyangxi/OpenOffice
